# 日进一步

> 你本来就该如此美好

个人项目管理工具，基于艾森豪威尔矩阵，帮你区分什么值得做、什么该糊弄、什么只是噪音。

## 理念

大多数效率工具都在推你"做更多"。日进一步在帮你**做更少但对的**。

- **长期项目**（重要不紧急）：没有完成，只有阶段。靠系统，不靠意志力。
- **短期项目**（重要且紧急）：周总结，月收获。每一次达成都是长期收益的具象化。
- **杂活**（紧急不重要）：糊弄糊弄就完了。不值得完美，做完就行。

总有一些时间，你不是工位上的标准件。

## 功能

- 四象限总览：长期 / 短期 / 杂活 / 日历
- 项目详情：复盘记录时间线、项目说明、备注
- 日历视图：有活动的日期自动点亮
- 数据导出：JSON 备份
- 侧边栏伸缩、响应式布局

## 技术栈

- React 18 + TypeScript
- Vite
- Tailwind CSS v4
- Zustand（状态管理 + localStorage 持久化）
- React Router（Hash 模式）
- date-fns

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:5173`
